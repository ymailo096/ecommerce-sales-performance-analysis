# E-commerce Sales Performance Analysis

End-to-end e-commerce data analysis focused on revenue performance, customer behavior, acquisition channels, geography, device usage, and data quality.

**Tools:** SQL · Python · Statistics · Tableau

## Business Problem

The goal of this project is to analyze e-commerce performance and identify the main factors affecting revenue and customer behavior.

The analysis focuses on:

- Revenue performance across regions, devices, and acquisition channels
- Customer behavior and differences between registered and anonymous users
- Product category performance
- Relationships between traffic, users, channels, and revenue
- Data quality issues that may affect business reporting

The final objective is to turn raw e-commerce data into actionable business insights and recommendations.
